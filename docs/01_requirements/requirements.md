# 要件定義書 (Requirements Specification)

## 1. プロジェクト概要
- **システム名称**: GoIPAM (Lightweight Go-based IP Address Management)
- **目的**: オープンソースIPAM「phpIPAM」のコア機能に焦点を絞り、Go言語およびモダンなSPA構成で再構築した、高速・軽量・ポータブルなIPアドレス管理システムを提供する。
- **実行基盤**: Docker / Docker Compose

---

## 2. スコープ定義

### 2.1 対象範囲 (In-Scope)
1. **IPv4 サブネット管理 (フラット構成)**
   - サブネットの登録・編集・削除 (CIDR形式: 例 `192.168.10.0/24`)
   - ネットワークアドレス、ブロードキャストアドレス、サブネットマスク、利用可能ホスト範囲の自動計算
   - サブネットごとの使用率 (登録IP数 / 総ホスト数) および空きIP数の可視化
   - 定期スキャン (Pingチェック / ホスト探索) の有効/無効フラグ設定

2. **IPアドレス管理**
   - サブネット内IPアドレスの登録・編集・削除
   - メタデータ管理:
     - ステータス (`Active`, `Reserved`, `DHCP`, `Offline`)
     - ホスト名 (DNS / FQDN)
     - MACアドレス
     - 説明・所有者メモ
     - 最終確認日時 (`last_seen`)
     - 死活ステータス (`online`, `offline`, `unknown`)
   - サブネット内の「最初の空きIP (First Available IP)」の自動探索・サジェスト機能

3. **PING生存確認 & ホスト自動探索 (Discovery)**
   - **オンデマンド実行**:
     - 単一IPに対する即時Ping実行
     - サブネット全体の即時Ping一括スキャン
     - サブネット全体のホスト自動探索 (全IPにPingを打ち、未登録の応答ホストを検出)
   - **定期バックグラウンド実行**:
     - 登録済みIPの生存確認 (Status Check)
     - 新規生存IPの探索 (Host Discovery)
   - **未登録IPの検出・取り込み**:
     - 検出された未登録ホストの一覧表示
     - ワンクリックでの正式IPアドレス登録機能

4. **Web UI (SPA)**
   - ダッシュボード (サブネット一覧、全体使用状況)
   - サブネット詳細ビュー (IP割り当てマトリクス / リスト表示、未登録検出ホストタブ)
   - ワンクリックでのPing実行、スキャン実行

---

### 2.2 非対象範囲 (Out-of-Scope)
- IPv6 サポート (将来拡張として考慮するが、初期フェーズでは対象外)
- サブネットの階層・ネスト構造 (フラットな管理に限定)
- ユーザー認証・権限管理 (社内LANやVPN内でのプライベート運用を前提とし、オープンアクセス)
- ラック・物理デバイス・VRF・VLAN等の複雑なインフラ管理 (メモ程度のVLAN ID項目のみ保持)
- マルチテナント・複数組織管理

---

## 3. 非機能要件
1. **パフォーマンス**:
   - Goのgoroutineワーカープールにより、/24 (254ホスト) のスキャンを数秒以内で完了可能とする。
2. **移植性・デプロイ容易性**:
   - `docker compose up -d` コマンド1つで、DB(PostgreSQL)、Backend(Go)、Frontend(Nginx+React) がすべて起動し即座に利用可能であること。
3. **拡張性・検証性**:
   - `.trace` フォルダ内の本家phpIPAMコードベースを参照・比較検証しやすい構造を維持する。
